# Data dictionary

Generated by `src/16_data_dictionary.py`. Row counts, columns and Hive types are read from the
files and from Hive; descriptions are written in the script. Step = numbered script in `src/`.

**Effective product sales** = `txn_type = 'sale' AND is_product AND NOT is_reversed` (see `src/03_etl_hive.py`); it is the default measure in steps 06-14.

## Hive tables (database `retail`, Hive local, embedded Derby metastore)

### retail.fact_sales (1,033,036 rows)

One row per cleaned invoice line (partitioned by year_month). Flags: txn_type, is_product, has_customer, is_reversed.

| Column | Type | Meaning |
|---|---|---|
| line_id | bigint | Surrogate key (row number ordered by time, invoice, stock code). |
| invoice | string | Invoice number; prefix C = cancellation, A = bad-debt adjustment. |
| invoice_ts | timestamp | Invoice timestamp (UK wall-clock time, stored as UTC). |
| date_key | int | FK to dim_date (yyyyMMdd). |
| hour | int | Hour of invoice_ts. |
| customer_id | int | FK to dim_customer; NULL when the customer is unknown. |
| stock_code | string | FK to dim_product (trimmed, upper-cased). |
| country | string | FK to dim_country. |
| quantity | int | Units; negative for cancellations. |
| price | decimal(12,3) | Unit price in GBP (3 decimals). |
| revenue | decimal(18,3) | quantity x price (negative for cancellations). |
| txn_type | string | sale / cancellation / adjustment. |
| is_product | boolean | False for postage, fees, vouchers, tests. |
| has_customer | boolean | customer_id is not NULL. |
| is_reversed | boolean | Sale line fully cancelled later, or the cancellation that reverses it. |
| source_sheet | string | Excel sheet the row came from. |
| year_month | string | Partition column (yyyy-MM). |
